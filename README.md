# Nandini's Developer Portfolio

## Project Overview
This is my personal developer portfolio website, created using HTML, CSS, and JavaScript as part of my Web Development Internship. It showcases my introduction, skills, projects, and contact information.

## Objectives
- To introduce myself.
- To display my technical skills and projects.
- To provide contact information.
- To learn and practice HTML, CSS, and JavaScript.
- To create a responsive and interactive portfolio website.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Web Browser

## Features
- About Me section
- Education section
- Skills section
- Projects section
- Contact form
- Internal navigation
- Profile image
- Responsive design

## HTML Features
- Semantic HTML elements
- Headings and paragraphs
- Forms and input fields
- Images and links
- Internal navigation

## CSS Features
- CSS Reset
- Background colors and text styling
- Header and navigation bar styling
- Hover effects
- Section spacing and alignment
- Responsive images
- Button styling
- Flexbox and layout styling
- Responsive design using media queries

## JavaScript Features
- Dark Mode and Light Mode toggle
- Contact form validation
- Name, email, and message validation
- Error messages for invalid inputs
- Success message after valid form submission
- Interactive website functionality

## Design
The website uses a modern and clean design with a professional layout. It includes Dark Mode and Light Mode options, attractive colors, smooth transitions, and a responsive interface for different screen sizes.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the Home, About, Skills, Projects, and Contact sections.
5. Try the Dark Mode toggle and contact form validation.

## What I Learned
I learned HTML structure, semantic elements, forms, images, links, CSS selectors, styling, Flexbox, responsive design, JavaScript DOM manipulation, event handling, theme switching, and form validation.
