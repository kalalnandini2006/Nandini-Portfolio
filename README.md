# Nandini's Developer Portfolio

## Project Overview
This is my first project is a personal portfolio website,
created using HTML, as part of my Web Development Internship.

## Objectives
- To introduce myself.
- To display my skills.
- To provide contact information.
- To learn basic HTML concepts.

## Technologies Used
- HTML5
- Visual Studio Code
- Web Browser
- CSS3
- JavaScript

## Features
- About Me section
- Skills section
- Contact form
- Internal navigation
- Profile image

## CSS Features
- Basic CSS Reset
- Background colors and text styling
- Header and navigation bar styling
- Hover effects on navigation links
- Section spacing and alignment
- Image responsiveness
- Button styling with hover effects
- Responsive design using media queries


## Design
The website uses a clean and simple design with a dark blue header, a light background, and blue buttons. CSS media queries help adjust the layout for smaller screens.


## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Navigate through the About, Skills, and Contact sections.

## What I Learned
I learned about HTML tags, headings, paragraphs, input fields, semantic tags,
forms, images, links, internal navigation and website structure.
